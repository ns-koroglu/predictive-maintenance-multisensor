## Project Title
Çoklu Sensör Füzyonu ve Yapay Zeka Tabanlı Erken Arıza Uyarı Sistemi ile Kestirimci Bakım Uygulaması

## Project Type
MTU-1 + graduation project infrastructure

## Main Goal
Develop a predictive maintenance pipeline using acoustic emission, vibration, and thermal data for early fault warning and anomaly detection.

## Scope
- Small-scale rotating machinery or bearing-focused setup
- Early warning and anomaly detection
- No full RUL prediction in the first phase
- Python-based modular implementation
- Small-dataset-friendly machine learning baseline

## Inputs
- Acoustic emission data
- Vibration data
- Thermal data
- Optional RPM / load / ambient temperature metadata

## Outputs
- Anomaly score
- Early warning flag
- Health state classification
- Evaluation plots
- Thesis-friendly reports

## Initial Models
- Isolation Forest
- One-Class SVM
- Random Forest
- XGBoost or LightGBM

## Constraints
- Limited hardware
- Dataset will be collected gradually over ~3 months
- Explainability is important
- System should be modular and academically defendable
