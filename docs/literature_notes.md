# Literature Notes

## Main themes
- Vibration-based fault diagnosis
- Acoustic emission for early damage detection
- Thermal monitoring
- Multi-sensor fusion
- Explainable AI in predictive maintenance

## Literature gaps
- Limited real-world long-term data
- Small dataset challenge
- Generalization problem
- Lack of explainability
- Few studies combining AE + vibration + thermal together

## Thesis positioning
This project focuses on early fault warning and anomaly detection
using multi-sensor fusion under small-data conditions.
